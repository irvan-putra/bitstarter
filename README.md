# bitstarter

A 2013 startup-class project built on the [heroku/node-js-sample](https://github.com/heroku/node-js-sample) template: a Node.js product landing page ("Monoton") plus the course's grading tooling.

Contents added on top of the template:

- `grader.js` + `checks.json` - a command-line grader that checks an HTML file (or URL) for required tags and attributes, using commander.js and cheerio.
- `index.html` - the product page: styled with the course's Bootstrap bundle, wired up with AddThis sharing, Google Analytics, and a Coinbase button for pre-ordering with bitcoin.

Written by hand in 2013, long before AI assistance. Course artifact, not maintained; the class services it integrated with (AddThis, Coinbase buttons, the course grader) are long gone. Credit for the base template goes to Heroku's node-js-sample.
